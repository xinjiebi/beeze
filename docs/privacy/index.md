# Beeze 隐私政策

**更新日期：2026年11月24日**<br>
**生效日期：2026年11月24日**

欢迎使用 Beeze。Beeze 是一款由 **XJBI**（以下简称“我们”）提供的本地音乐播放应用。

我们重视你的隐私。本政策将说明 Beeze 如何处理你的本地音乐及相关数据、申请哪些系统权限，以及广告服务可能涉及的数据处理。

**Beeze 无需注册账号，不提供云端存储服务，不会向开发者上传你的歌曲、歌词、封面、播放记录、喜欢列表或自建歌单。应用接入 Google AdMob 广告及相应的隐私同意服务，相关数据可能由 Google 及其合作伙伴按照本政策第三节所述方式处理。**

## 一、我们处理的信息

为了提供本地音乐播放与管理功能，Beeze 会在你的设备本地处理以下信息：

1. **本地音频及元数据**
   - 包括音频文件、歌曲名称、艺术家、专辑、封面、时长等信息。
   - 用于扫描音乐库、展示歌曲、搜索、排序和播放音乐。

2. **本地歌词文件**
   - 在你授权后，Beeze 会读取歌曲所在目录中的 `.lrc` 歌词文件。
   - 用于展示静态歌词和动态歌词。

3. **应用内生成的数据**
   - 包括最近播放记录、喜欢列表、自建歌单、播放队列、歌曲展示名称、扫描过滤记录及相关设置。
   - 用于提供最近播放、收藏、歌单管理、修改展示名称和过滤歌曲等功能。

以上本地音乐及个人内容不会由开发者远程收集或获取，也不会由 Beeze 主动提供给广告合作伙伴用于匹配你的音乐内容。

## 二、数据存储与网络服务

- 歌曲、歌词、封面、播放记录、喜欢列表、自建歌单和扫描过滤记录仅保存在你的设备上。
- Beeze 已申请 Android 的 INTERNET 网络权限，用于加载本隐私政策、请求和展示广告，以及提供广告隐私同意功能。
- Beeze 不会通过互联网向开发者上传你的歌曲、歌词、封面、播放记录、歌单或其他本地音乐内容。
- 加载隐私政策时，GitHub Pages 会接收提供网页所需的标准网络请求信息（例如 IP 地址），其数据处理适用 GitHub 的隐私政策。
- Beeze 已关闭 Android 系统应用数据云备份功能。
- 你设备上的原始音频和歌词文件仍保存在其原有位置，不会因卸载 Beeze 而被删除。

## 三、广告服务与隐私同意

Beeze 使用 **Google Mobile Ads SDK（AdMob）**提供横幅、原生和开屏广告，并使用 **Google User Messaging Platform（UMP）**在适用法律要求时获取和管理广告隐私同意。

广告及同意服务可能由 Google 及其广告合作伙伴处理以下信息：

- IP 地址、设备型号、操作系统、语言和一般设备信息；
- Android 广告 ID 或其他设备标识符（取决于系统设置和可用性）；
- 广告请求、展示、点击及其他广告交互信息；
- 大致位置信息（例如可能由 IP 地址推断）；
- 与广告服务性能、故障诊断和防止欺诈相关的信息。

这些信息可能用于展示个性化或非个性化广告、衡量广告效果、限制广告展示频次、检测无效活动以及维护广告服务。即使选择非个性化广告，广告服务仍可能处理提供广告所必需的信息。具体处理方式取决于你的地区、系统设置、同意选择及 Google 的广告配置。

在适用法律要求时，Beeze 会在请求广告前通过 UMP 征求你的同意。你可以通过系统设置管理广告 ID；当 Google 要求提供隐私选项入口时，也可以前往“关于 → 广告隐私选项”查看或修改你的选择。

Google 及其合作伙伴的数据处理适用其各自的隐私政策。你可以查阅 [Google 隐私政策](https://policies.google.com/privacy)以及 [Google 如何使用网站和应用信息](https://policies.google.com/technologies/partner-sites)。

## 四、系统权限说明

Beeze 仅在为提供相应功能所必需时申请以下权限：

### 1. 音频及存储读取权限

- Android 13 及以上版本使用“读取音乐与音频”权限。
- Android 12 及以下版本使用相应的存储读取权限。
- 用于扫描、展示和播放设备中的本地音频文件。
- 如果拒绝该权限，Beeze 将无法扫描和播放本地音乐。

### 2. 歌词文件夹访问

- Beeze 不申请“所有文件访问权限”。
- 如需显示本地歌词，你可以在“关于 → 歌词文件夹”中主动选择一个或多个文件夹。
- Android 的存储访问框架仅允许 Beeze 读取你选择的文件夹，用于查找和读取与歌曲配套的 `.lrc` 文件。
- 不选择歌词文件夹不会影响音乐扫描、播放、歌单或歌曲名称搜索。
- 你可以随时在“关于 → 歌词文件夹”中移除已授权的文件夹；移除后，Beeze 将无法继续读取其中的歌词。

### 3. 通知权限

- 用于显示媒体播放通知、当前播放状态以及播放、暂停、切换歌曲等控制按钮。
- 拒绝通知权限不会影响 Beeze 应用内的正常播放操作。

### 4. 前台媒体播放服务

- 用于在你离开应用界面或锁屏后保持音乐播放，并通过系统媒体通知提供播放控制。
- 该服务不用于收集或上传个人信息。

## 五、删除、修改与恢复

- **修改歌曲名称**：仅修改歌曲在 Beeze 内的展示名称，不会修改原始音频文件的文件名或元数据。
- **删除歌曲**：在 Beeze 中删除本地歌曲，只会将该歌曲加入应用的扫描过滤列表，不会删除设备上的真实音频文件。
- **恢复歌曲和文件夹**：你可以前往“首页 → 扫描 → 管理”查看已过滤的歌曲和文件夹，并在需要时解除过滤。
- **删除歌单**：删除自建歌单不会删除其中的歌曲，也不会修改或删除原始音频文件。
- **清除应用数据**：你可以通过 Android 系统设置清除 Beeze 的应用数据。广告同意状态及本地广告展示冷却记录也会被清除；Google 或广告合作伙伴持有的数据需按照其隐私政策另行管理。
- **卸载应用**：卸载 Beeze 会清除其保存的本机应用数据，但不会删除设备上的原始音频和歌词文件。

## 六、信息的共享、转让与公开披露

我们不会向第三方共享、转让或公开披露你的歌曲、歌词、播放记录、喜欢列表、自建歌单等本地音乐内容。

Google 及广告合作伙伴可能为提供广告、衡量效果、防止欺诈及遵守法律义务而处理或共享第三节所述的广告相关数据。Beeze 不出售你的本地音乐内容或应用内个人列表。

## 七、你的权利与选择

你可以通过以下方式管理自己的信息和权限：

- 在 Android 系统设置中允许或撤回音频、文件和通知权限。
- 在 Beeze 中管理喜欢列表、自建歌单和扫描过滤记录。
- 通过系统广告设置，以及适用时通过“关于 → 广告隐私选项”管理广告选择。
- 清除应用数据或卸载 Beeze，以删除 Beeze 保存在本机的应用数据。

撤回某些权限可能导致相应功能无法使用，但不会影响撤回前基于该权限已完成的本地功能处理。

## 八、未成年人保护

Beeze 不专门面向未成年人，也不会由开发者主动收集未成年人的个人信息。未成年人应在监护人的指导和帮助下使用本应用及阅读本政策。广告内容和数据处理方式还可能受应用的目标受众及广告配置影响。

## 九、信息安全

Beeze 通过本地处理音乐内容、限制权限用途、仅在必要时接入广告网络服务，以及关闭应用数据云备份等方式降低个人信息风险。

请注意，设备丢失、系统漏洞、恶意软件、网络传输或未经授权的设备访问等风险并非应用能够完全控制。建议你及时更新设备系统，并妥善保管自己的设备。

我们可能会根据功能变化或适用法律法规的要求更新本政策。更新后，我们会在本页面公布最新版本，并更新页面顶部的日期。

如果更新涉及个人信息处理目的、处理方式或信息类型的重大变化，我们会通过应用内提示等合理方式告知你，并在需要时重新征得你的同意。
